Read down the table, the search compensates for the degrading input in a
consistent way: the model gets wider ($128\to192\to256$), the dropout rises
($\num{0.042}\to\num{0.182}\to\num{0.222}$) and at the last level the temporal
window doubles. Capacity and regularisation increase together, because the
per-frame information is weaker and more context is needed to recover the same
signal.
